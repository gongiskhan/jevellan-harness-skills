# jevellan-harness-skills

Skills that turn a Claude Code session into a coordinator: it distributes work to other sessions, has Jev choose
model, effort and provider for every step, runs each step as its own session on the runtime that fits, and keeps a
durable ledger so that any session can resume.

Work in progress. The full README (install, first run, how the chain works, adding a provider, adding a skill) comes
with version 0.1.0.
