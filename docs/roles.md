# Roles

Generated by `node scripts/check-roles.mjs --write` from the frontmatter of every `skills/*/SKILL.md`. Do not
edit it by hand: change the skill, run the command again and commit the result. `npm test` runs
`node scripts/check-roles.mjs --check`, which fails while this file is stale.
